# GraySlate's Miscellaneous Vocalsynth and Music Resources
Repository for miscellaneous resources made by GraySlate for vocalsynth and music production.

## ARPASing to VCCV Replace List
A replace list for use in iroiro2 that replaces APRASing phonemes in a UST with VCCV English/Cz-Sampa phonemes.  Recommend for use in Classic UTAU (though plugin will also work in OpenUTAU).

## ARPASing/VCCV to GrayGlish 1.0 and 2.0 Replace Lists
Replace lists for iroiro2 that replace ARPASing and VCCV ENG phonemes in USTs with GrayGlish 1.0 or 2.0 X-Sampa phonemes.  Meant to automate conversion and save time when converting phonemes to GrayGlish.  Duplicates for ARPASing go up to 5.

## EN X-Sampa Phonemizer Replacement Dictionary File 
GrayGlish 1.0 and 2.0-specific replacement EN X-Sampa Dictionary replacement yaml file.  Creates a better base phoneme transcription for GrayGlish when using the EN X-Sampa OU Phonemizer that overrides the default.  Dictionary file can be edited at any time.
